# Vista

Configurable list/board views in DevRev. Vistas allow users to create filtered, grouped, and sorted views of objects (tickets, issues, etc.) and save them for reuse.

**Capabilities:**
- Configurable widgets, filters, drill-throughs
- Saved views appear in Explore section under My Views or Shared
- Pin views to left navigation for quick access
- View types: List views, Board views, Dashboards, Sprint Boards
- Support grouping by attributes (owner, parts, stage, etc.) and column customization
- Export available via Actions button

See [[features/analytics]] for dashboard capabilities.
