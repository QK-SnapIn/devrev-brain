# Shadow User

A non-access tracking user created by data imports via AirSync ([[glossary/airsync]]). Shadow users have no app access and exist solely for tracking purposes -- they represent users from external systems whose data has been synchronized into DevRev. They appear in ticket attributes (e.g., as reporters or email members) but cannot log into the DevRev application.

See [[entities/dev-user]] for the full user type taxonomy.
