# Airdrop

DevRev's data import engine for bringing data from external systems into DevRev. Supports field mapping, type mapping, and filter-by-value.

**Import modes:**
- **Initial import:** One-time bulk import from an external system.
- **Periodic sync:** Ongoing sync at configurable intervals.

**Configuration:** Settings > Integrations > Airdrops. Automations on imported items can be toggled on/off.

Contrast with [[glossary/airsync]], which provides real-time bidirectional sync.

See [[features/airdrop]] for full details.
