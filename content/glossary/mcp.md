# MCP (Model Context Protocol)

DevRev's remote MCP server (`https://api.devrev.ai/mcp/v1`) allows external AI agents (Claude, Copilot, Gemini, etc.) to call DevRev actions as tools. DevRev also acts as an MCP client — workflows can call external MCP servers.

See [[features/remote-mcp]] for full details.
