# NNL (Now/Next/Later)

A view for organizing issues by time horizon. NNL maps issues into three buckets:
- **Now** -- current sprint / immediate work
- **Next** -- upcoming sprint / near-term planned work
- **Later** -- backlog / future work

Used in the Work section for sprint and roadmap planning.

See [[entities/issue]] for issue management details.
