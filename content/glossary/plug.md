# PLuG

Customer-facing chat widget embedded in your product (web/mobile SDK). PLuG creates conversations in DevRev Inbox when customers send messages.

**Configuration:** Install PLuG snap-in via Settings. Configure brand logo, default bot name, and Turing AI mode (assist or automated). Requires code integration to map user identity from your app to DevRev.

**Capabilities:**
- Supports AI agent ([[glossary/turing]]) for automatic deflection
- Creates [[entities/conversation]] objects in Inbox
- Surfaces [[entities/article]] content from the knowledge base

See [[features/conversations]] for details.
