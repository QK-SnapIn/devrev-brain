# Task

## What it is
A lightweight work object used for breaking down work into smaller actionable pieces. Separate from issues — tasks are simpler and do not carry the full lifecycle of an issue.

## Key attributes
- Lightweight work object, separate from issues; intended for smaller, non-engineering to-dos.
- First-class object in DevRev alongside Issues, Tickets, and Enhancements.
- Can be assigned to users.
- **Task Tracker** snap-in available for monitoring and reporting.
