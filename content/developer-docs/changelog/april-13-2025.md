# April 13, 2025

## [Modified Endpoints](#modified-endpoints)

### [SLAs](#slas)

Added field `in_policy` to SLA metric target to indicate whether the metric is in the active SLA policy

### [Webhooks](#webhooks)

New event types added to webhook related endpoints:

* `dashboard_created`
* `dashboard_deleted`
* `dashboard_updated`
* `widget_created`
* `widget_deleted`
* `widget_updated`
