# May 19, 2025

## [New Endpoints](#new-endpoints)

### [Artifacts](#artifacts)

* [`/artifacts.versions.delete`](https://developer.devrev.ai/api-reference/artifacts/hard-delete-version) - Delete artifact versions
* [`/artifacts.versions.prepare`](https://developer.devrev.ai/api-reference/artifacts/versions-prepare) - Prepare artifact versions

### [Links](#links)

* [`/links.replace`](https://developer.devrev.ai/api-reference/links/replace) - Replace links

### [Metric Trackers](#metric-trackers)

* [`/metric-trackers.get`](https://developer.devrev.ai/api-reference/slas/metric-trackers-get-post) - Get metric tracker details

## [Modified Endpoints](#modified-endpoints)

### [Accounts](#accounts)

Added `tier` filter support to:

* [`/accounts.export`](https://developer.devrev.ai/api-reference/accounts/export-post)
* [`/accounts.list`](https://developer.devrev.ai/api-reference/accounts/list-post)

### [Articles](#articles)

Modified schema for:

* [`/articles.create`](https://developer.devrev.ai/api-reference/articles/create-article)
  + Made `applies_to_parts` optional (removed min items constraint)
  + Added `content_format` and `data_sources` properties
* [`/articles.update`](https://developer.devrev.ai/api-reference/articles/update-article)
  + Added `content_format` and `data_sources` properties

### [Conversations](#conversations)

* [`/conversations.list`](https://developer.devrev.ai/api-reference/conversations/list-post) - Added `state` and `actual_close_date` filters
* [`/conversations.update`](https://developer.devrev.ai/api-reference/conversations/update) - Made empty owner sets allowed (removed min items constraint)

### [Groups](#groups)

Added new filters to [`/groups.list`](https://developer.devrev.ai/api-reference/groups/list-post):

* `created_by`
* `name`
* `sync_metadata` related filters

### [SLAs](#slas)

Added `tier` support to account selector in:

* [`/slas.create`](https://developer.devrev.ai/api-reference/slas/create)
* [`/slas.update`](https://developer.devrev.ai/api-reference/slas/update)

### [Webhooks](#webhooks)

Added new event type `sla_tracker_fetched` across webhook endpoints:

* [`/webhooks.create`](https://developer.devrev.ai/api-reference/webhooks/create)
* [`/webhooks.event`](https://developer.devrev.ai/api-reference/webhooks/event)
* [`/webhooks.get`](https://developer.devrev.ai/api-reference/webhooks/get-post)
* [`/webhooks.list`](https://developer.devrev.ai/api-reference/webhooks/list-post)
* [`/webhooks.update`](https://developer.devrev.ai/api-reference/webhooks/update)

### [Works](#works)

Added sync history filters to:

* [`/works.export`](https://developer.devrev.ai/api-reference/works/export-post)
* [`/works.list`](https://developer.devrev.ai/api-reference/works/list-post)
