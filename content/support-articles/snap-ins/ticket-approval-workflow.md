# Ticket approval workflow

The [[entities/ticket|Ticket]] approval workflow enables support [[features/agents|agents]] to request approvals from stakeholders directly within support [[features/tickets|tickets]].

For more information, refer to the [Ticket approval workflow snap-in](https://marketplace.devrev.ai/ticket-approval-workflow) on the DevRev marketplace.

## Installation

1. In DevRev, go to **Settings** > **Snap-ins** and click **Explore Marketplace** in the top-right corner.
2. In the DevRev marketplace, find **Ticket approval workflow** and click **Install**.
3. In DevRev, **Snap-ins** > **Ticket approval workflow** > **Configure**.
4. Enter the required parameters like **Delay in seconds**.
5. Click **Save** and **Install snap-in**.

## Usage

On the ticket execute the `/request_approval` command with the parameter number of approvers.
