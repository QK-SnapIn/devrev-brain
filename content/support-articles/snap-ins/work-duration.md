# Work duration

[Work duration](https://devrev.ai/marketplace/work-duration) offers the ability
to track how much work [[features/issues|issues]] and [[features/tickets|tickets]] took to complete, measured by time
spent in work sessions.

The snap-in adds a new attribute to tickets and issues which automatically
calculates the work duration for that item. Work duration is meassured in time
spent through work sessions. A work session starts when a work item is created
or reopened and ends when the item is closed. The work duration can be shown in
hours or days.

## Installing the Work duration snap-in

1. Install the [Work duration](https://devrev.ai/marketplace/work-duration) from
   the DevRev marketplace.
2. Select whether work duration time should be displayed in hours or days.
3. Click **Install snap-in**.
