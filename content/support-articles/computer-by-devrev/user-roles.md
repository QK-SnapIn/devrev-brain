# User roles

User roles are used to manage the access and permissions of users in an organization.

### Create a user role

1. Under [**Settings** > **User Management** > **Roles**](https://app.devrev.ai?setting=user-roles),
   select **+ Create new**.
2. Enter the role name and description.
3. Select an object, such as **Ticket** or **Inbox**, to assign permissions.
4. To restrict permissions, select **+ Add condition** and create a custom
   condition.
5. To apply privileges to all subtypes of the object, select **Apply to all
   subtypes**.
6. To configure privileges for specific subtypes:

   1. In the subtype section of the object, select **Add**.
   2. Select the subtype to update privileges.
   3. To further restrict privileges, add a custom condition as with object
      roles.
7. Select **Save**.

![Create a user role](don:core:dvrv-us-1:devo/0:artifact/4100385)

### Update a user role

1. In [**Settings** > **User Management** > **Roles**](https://app.devrev.ai?setting=user-roles), select the role to update.
2. Select **Edit**.
3. Update the role details.
4. Select **Save**.

![Update a user role](don:core:dvrv-us-1:devo/0:artifact/4100386)

### Assign a user role

1. In [**Settings** > **User Management** > **Roles**](https://app.devrev.ai?setting=user-roles), select the role to assign.
2. Select **Assign role**.
3. To assign the role to a group:

   1. Select **+ Group**.
   2. Search for and select the groups.
   3. Select **Assign role**.
4. To assign the role to a user:

   1. Select **+ User**.
   2. Search for and select the users.
   3. Select **Assign role**.

![Assign a user role](don:core:dvrv-us-1:devo/0:artifact/4100389)

You cannot assign a role to the **All users** group.
