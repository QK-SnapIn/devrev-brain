# March 2026

# Customization

## Custom objects

Fields of type custom object now display meaningful labels instead of IDs in group-by keys. This enhancement improves data clarity in Vista columns, making it easier for users to understand and interpret information at a glance. Users can now identify and work with custom objects more easily, streamlining their workflow and boosting efficiency.

# Support App

## Edit organization schedules

Administrators can now update organization schedules at any time, whether before or after expiry.

**What's New:**

* **Edit anytime:** Modify validity periods, operating days, timings, and holidays for any organization schedule without restrictions.
* **Version control:** Publishing updates creates a new version of the schedule. Existing items retain the previous version, while the new version applies to items created afterward.

**Note:** For SLAs, when a ticket's policy is updated, the latest version of the organization's schedule associated with that policy will be applied.
