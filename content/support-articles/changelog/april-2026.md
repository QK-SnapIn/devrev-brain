# April 2026

## Analytics Platform

### **Fast & near real-time dashboards**

Computer cache is now generally available, bringing significantly faster dashboard load times and near real-time data – all powered by local query processing through the Computer desktop app.

**What you get:**

* **Faster dashboards** – widget queries run locally, making data access significantly quicker than before.
* **Near real-time data** – dimension dataset widgets refresh every 30 seconds automatically.
* **Silent, stable updates** – only changed widgets re-render; layout and scroll position stay intact.
* **Resilient to failures** – last good data persists during network [[features/issues|issues]]; a subtle "reconnecting" badge appears if offline for more than 30 seconds.

**Getting started:** See the [Computer App for Analytics](https://support.devrev.ai/en-US/devrev/article/EJ81Z-LV-computer-app-for-analytics) guide to set up and get the most out of this feature.

You can now set custom reminders on any comment by selecting a specific date from the calendar or simply typing the date and time in natural language. Stay on top of your [[entities/task|tasks]] with timely reminders that work for you.
