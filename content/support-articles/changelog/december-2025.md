# December 2025

# Analytics Platform

## **Shortened dashboard URL for copy link functionality**

The **copy link** option on the dashboard now generates a streamlined URL for easier sharing, following the app-wide format such as `<https://app.devrev.ai/../dashboard/dashboard-xyzw>`.

## **Self serve custom dashboards**

The new percentile functions for dashboard widgetsintroduce the ability to create widgets with additional aggregations, including P50, P90, P95, and P99 percentiles, offering enhanced data analysis with a variety of metrics.

## **Widget customization improvements**

The **Select/Unselect All** option in the **Customize** dropdown lets you manage column selections, enhancing your experience with table widgets.

# Multilingual article search

Introducing multilingual search for [[entities/article|articles]], allowing content access in English, French, Spanish, German, Italian, Portuguese, and Japanese.

**Improvements**:

* Updated search indexer with a multilingual embedding model for better accuracy.
* Enhanced syntactic indexer with tokenizer plugins for improved keyword matching.

# Record View

* Subtype specific [[features/templates|templates]] now appear at the top of the list, minimizing scrolling and clicks when applying templates after selecting a subtype.
* Records now display a condensed preview for rich text fields with a **View more** option to view the full content in a modal. Editing rich text fields opens directly in an expanded modal, providing more space for long-form content and rich formatting.

# Support App

* Fixed an [[entities/issue|issue]] with Japanese language article titles not displaying correctly.
* Added support for granular access control for [[entities/conversation|conversation]] owners. For example, you can now create access policies like Create, Read, and Update permissions only when the user is the owner.
* Fixed a bug that required end users to manually refresh to see updates on the [[entities/ticket|ticket]].
* Enabled [[features/customization|customization]] of the rating scale for Conversation and Ticket [[glossary/csat|CSAT]], allowing flexibility from the previous fixed 5 point scale to an N point scale.
* Added a configuration option in the email snap-in to enable or disable Ticket details (Re:TKT-xxx) by default in every reply.
* Added an **[[entities/account|Account]]** field filter in the Ticket List view. Renamed **Customer Workspace** to **Workspace** on [[features/tickets|tickets]]. Both fields are now filterable.
* The Escape key now closes the ticket pane on the [[features/customer-portal|customer portal]].
* Fixed a bug where certain fields displayed empty values in the **List View** but showed the correct values in the **Ticket Detail** view.
* Improved background image loading speed on the customer portal.
