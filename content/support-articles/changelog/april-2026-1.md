# April 2026

# Analytics Platform

## **Computer Cache for Analytics — Fast & near real-time dashboards**

Computer cache is now generally available, bringing significantly faster dashboard load times and near real-time data – all powered by local query processing through the Computer desktop app.

**What you get:**

* **Faster dashboards** – widget queries run locally, making data access significantly quicker than before.
* **Near real-time data** – All widgets powered by current-state data (like [[features/tickets|tickets]], [[features/issues|issues]], and [[features/accounts|accounts]] as they look today) automatically refresh every 30 seconds.
* **Silent, stable updates** – only changed widgets re-render; layout and scroll position stay intact.
* **Resilient to failures** – last good data persists during network issues; a subtle "reconnecting" badge appears if offline for more than 30 seconds.

**Getting started:** See the [Computer Cache for Analytics](https://support.devrev.ai/en-US/devrev/article/EJ81Z-LV-computer-app-for-analytics) guide to set up and get the most out of this feature.

## Dashboard Visualisation

### **Date-time labels — context-aware formatting**

Date and time labels on charts now adapt automatically based on the data range in view.

* **Dynamic date-time formatting** – labels adjust to show only what's relevant for the time range, eliminating redundant information like a repeated year on every label
* **No overlapping labels** – spacing is handled automatically so readability is never compromised
* **No loss of context** – you always have enough information to understand exactly what you're looking at

### **Column & bar charts — smarter use of space**

Columns and bars now scale dynamically to fill the available chart area.

* **Dynamic widths** – bars and columns adapt to the chart size instead of being fixed at 16px, making full use of the available space.
* **No unnecessary gaps** – visuals feel balanced and proportional regardless of how many data points are shown.
* **Easier value comparison** – subtle differences between values are more apparent at a glance.
* **Consistent across all variants** – applies to grouped, ungrouped, and stacked chart types.

### Chart legends — improved interaction & clarity

A set of focused improvements to make working with chart legends cleaner and more intuitive.

* **"View All" popover** – hovering over the "View All" option now shows the complete list of legends in a popover, so you can access all data points without leaving the chart.
* **Select / deselect all** – toggle all legends on or off in one click, making it easier to isolate or compare specific data series.

# Build App

## **Sprint board 2.0 — Sprint boards just got a major upgrade**

From how you set up sprints to how you run them day-to-day, we've overhauled the sprint board experience end-to-end

**Setting up sprints**

* **Plan N sprints ahead** – Auto-create and view multiple future sprints in one place
* **Edit sprint dates with one click** – Update start and end dates for active sprints directly from the board
* **Configure cycle length & buffer time** – Set sprint duration and cooldown periods at the board level
* **Full sprint history** – Navigate past sprints without the previous 3-sprint limit
* **Persistent filters** – Sprint board filters now save automatically across sessions

**Running sprints**

* **Sprint goals in context** – View sprint goals alongside your issues in an aside panel; get notified in-app when you're tagged in goal section
* **Auto-rollover incomplete issues** – Unfinished issues move to the next sprint automatically. You can opt-in and opt-out the automations from sprint board settings
* **Sprint-end reminders** – A timely [[glossary/nudge|nudge]] 3-4 days before the sprint closes
* **Timeline discussions** – Discuss and track changes directly on the sprint board, with a full event log of what changed and who changed it
* **Sprint insights, refreshed in real-time** – real-time sprint insights with simplified metrics and a snapshot captured at sprint end. Please keep the computer desktop app running in the background for real time insights

## **Roadmap Execution Tracking pre-built dashboard**

Engineering managers and PMs can now track roadmap progress out of the box – no custom setup needed. *Just [[features/search|search]] for "Roadmap Execution Tracking" in CMD + K (mac) or CTRL + K (windows)*

**What's new:**

* **Health field on [[entities/enhancement|enhancements]]** – Mark each [[entities/enhancement|enhancement]] as On Track, At Risk, Off Track, or Not Applicable at a glance
* **Status update field** – Add a free-text status note directly on enhancements to capture context alongside health
* **Stock execution tracking dashboard** – A pre-built dashboard seeded in every org covering two views:

  + *Roadmap progress & health* – real-time view of what's on track, at risk, or delayed.
  + *Planned vs actual* – delivery progress updated up to every hour.

Answers the questions your weekly rituals are built around: what's on track, what's slipping, and where does the team need help.

## **New code change object model via Git integration**

We've introduced a new custom **Code Change object** to replace the stock code change object, laying the foundation for richer GitHub data and more powerful Dev360 [[features/analytics|analytics]] & conversational search on PR data

**What's new:**

* **Improved data model** – A dedicated Code Change object with a well-defined schema, enabling more structured and extensible tracking of GitHub activity
* **[[entities/issue|Issue]] ↔ Code Change linking** – PRs and issues can now be linked via the new object, giving you clearer traceability between code and work items
* **Searchable & analytics-ready** – Code Change data is now searchable and available for analytics, powering conversational Dev360 & dashboards
